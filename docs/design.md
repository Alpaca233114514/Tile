# 视觉与交互规范

品牌名 Tile；平台项目名 mac-widgets-windows / mac-widgets-gnome。

| 层级 | 规范 |
| --- | --- |
| 基础值 | 8 px 网格；16 px 间距；24 px 圆角；20 px 卡片内边距 |
| 语义 | 浅色纸白 #F6F5F1 / 深色墨灰 #242831；强调色 #537C65；天气蓝 #456E9A |
| 组件 | 小 192×192；中 400×192；大 400×400，均为逻辑像素 |
| 排版 | 平台系统字体；正文 14；标签 12；主数字 48–64 |
| 状态 | 悬停反馈、键盘焦点；编辑入口始终可发现；加载、无数据、失败状态分开 |

使用平台原生文字和图形。透明为半透明卡片，demo 不声称实现系统级模糊或 Liquid Glass。两端共享此文档，分别维护原生视觉值。

启动直接展示桌面组件，不自动弹出组件库。应用窗口正常遮住组件，编辑也不改变其桌面归属。卡片非按钮区域可直接拖动，无需进入编辑；小幅移动不触发拖动，松手吸附 8 px 网格并保存。右键可调整尺寸、配置或移除；编辑入口仅突出显示卡片。组件库仅在用户主动添加或配置时打开。Windows 卡片不作为普通应用窗口参与 Alt+Tab。

照片空态明确显示“选择本地照片”，不使用装饰性风景假装已有照片。两端均提供直接调用系统选择器的按钮；Windows 另外支持拖入图片。主题提供系统、浅色、深色。
