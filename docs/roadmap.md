# 开发路线与验收

| 版本 | 目标 |
| --- | --- |
| v0.1 demo | 两个独立原生工程；时钟、天气、照片、日历；图形管理；拖拽、尺寸、主题、保存 |
| v0.2 | 便签、待办；无障碍；照片轮播；组件库细化 |
| v0.5 | 音乐、电池、系统监控、新闻、股票、计算器；完整多显示器恢复策略 |
| v1.0 | 安装器 / MSIX / GNOME 扩展发布；更新、签名、长期稳定性 |

demo 验收：

- 添加同类组件两次，分别配置；移除一个，重启后保持。
- 拖动松手后吸附；切换三种尺寸和三种主题。
- 搜索城市，明确选择地点；验证天气更新和断网状态。
- 选照片后重启；原文件缺失时出现占位。
- Windows 默认桌面模式测试 Win+D、图标点击、编辑拖拽、Explorer 重启、显示器拔插与不同 DPI。
- GNOME 在 Debian 实际 Wayland 会话中测试启用、停用、锁屏、概览、重登及桌面图标扩展共存。

Windows 不注入 Explorer 右键菜单；使用托盘和卡片菜单作为 demo 入口。GNOME 尝试扩展现有背景菜单，桌面图标扩展接管菜单时使用顶栏入口。多显示器仅保证把组件限制到一个当前可见工作区，跨屏恢复待真实环境验证。
